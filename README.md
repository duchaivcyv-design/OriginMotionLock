# OriginMotionLock
Tweak iOS (Rootless) mang hiệu ứng hình nền chuyển động theo góc nghiêng kiểu OriginOS lên màn hình khóa iPhone.

## Tính năng:
- Sử dụng cảm biến chuyển động (CoreMotion) mượt mà.
- Chống khựng/giật lag bằng thuật toán nội suy (Lerp).
- Hỗ trợ jailbreak Rootless (Dopamine, Palera1n,...).
